# Milestone 1: Application Foundation

The initial scaffold established the DocuMind repository and local development baseline. The backend exposes `GET /health`, and the frontend renders a static Next.js application shell. The health endpoint confirms that the API process responds; it does not perform dependency checks.

The initial automated test checks the health route's HTTP status and JSON response. Database persistence is covered by the follow-on Milestone 1A foundation in [milestone-1a-database.md](milestone-1a-database.md).

Use the commands in the root [README](../README.md) to run the applications and test locally. Keep later capabilities scoped to their approved milestones and update this document when the foundation changes.
